# Ski Form 2

Браузерная студия постановок беговых лыж, палок и регулируемого манекена. Геометрия приблизительная, без текстур. Лыжи основаны на пропорциях Denton Aura; крепления — на референсах NNN Step.

## Запуск

`node server.mjs` → http://127.0.0.1:4173.

Статические файлы находятся в `dist/`. Нужен HTTP сервер: ES модули не запускаются через file://. Three.js 0.180.0 включён локально, лицензия MIT лежит в `dist/vendor/LICENSE`. Шрифт Golos Text загружается с Google Fonts; предусмотрен системный запасной шрифт.

## Сцена и человек

- Лыжи, палки и человек включаются независимо. Скрытие предмета сохраняет его постановку.
- Шесть раскладок инвентаря и шесть поз человека: стойка, классический шаг, коньковый толчок, двойной толчок, низкая стойка, вертикальные лыжи в руке.
- Рост манекена 100–210 см. Руки и ноги решаются двухзвенной обратной кинематикой с сохранением длины сегментов и ограничением сгиба. Недостижимая цель отмечается сообщением.
- Редактируются таз, корпус, голова, кисти, стопы, направление локтей и коленей, сгиб конечностей, поворот запястий и голеностопов. Пятка поднимается относительно носка.
- Клик по части тела выбирает её; цветные точки можно перемещать в кадре. Корпус и голову можно вращать кольцами. Весь манекен перемещается как отдельный объект через список объектов.
- У каждого предмета отдельная привязка: свободно, левая/правая стопа, левая/правая кисть. Переключение связи сохраняет мировое положение. «Совместить» переносит предмет к выбранной точке. Две лыжи можно связать с одной кистью.
- У палок выбирается хват за рукоятку или середину; дополнительная опция ставит наконечник на землю. Размеры инвентаря не меняются при смене роста.

## Инвентарь, кадр и PNG

Независимые предметы, групповое выделение, мировые/локальные оси, точные координаты и повороты, шаг 1 см / 15°, история отмены. Пять направлений камеры, перспектива/ортография, фокусное расстояние, три материала и регулируемый свет.

Для креплений доступны NNN Step, один узкий тёмный прямоугольник и отсутствие креплений. Крепления, ремешки, длина/ширина лыж, загиб носка и длина палок регулируются отдельно от манекена.

«Тени» выключает все отбрасываемые тени, включая тени на предметах. Земля — конечная плоскость с контуром и сеткой 20 см. Её размеры и высота задаются в сантиметрах; «Под комплект» ставит поверхность под нижней точкой видимых предметов. Земля фиксирована по высоте. Опция «Земля в PNG» независимо управляет её экспортом.

PNG: 1024 / 2048 / 4096 по длинной стороне, 1:1 / 3:4 / 4:3 / 9:16, белый / серый / прозрачный фон. Выделение, гизмо, точки суставов и сетка редактора не экспортируются. Готовый PNG доступен и по повторной ссылке под экспортом.

## Локальные пресеты и обмен

Отдельного бэкенда и синхронизации пользовательских сцен нет. Рабочая сцена и библиотека хранятся в localStorage этого браузера для текущего адреса сайта. Геометрия и изображения в пресеты не включаются.

«Мои пресеты»: сохранить новый с именем, открыть, обновить, переименовать, создать копию, удалить с возможностью вернуть удалённый пресет. Есть поиск и индикатор размера. Бюджет библиотеки — 3.5 МиБ UTF-16, до 500 записей; оставлен запас для автосохранения сцены. При ошибке записи прежняя библиотека не заменяется.

«Скачать JSON» сохраняет одну текущую сцену, меню пресета — выбранную сохранённую сцену, «Скачать всю библиотеку» — весь набор. Импорт принимает один пресет, набор или старую сцену версии 1. Все записи проверяются до добавления; импорт добавляет новые копии, совпадающие имена получают суффикс. Старые пользовательские композиции и настройки инвентаря сохраняются.

«Поделиться» создаёт ссылку с одной сценой в URL-фрагменте. При наличии CompressionStream используется deflate; иначе JSON кодируется без сжатия. Получатель просматривает название и добавляет сцену отдельной копией. Для частной опубликованной студии получателю требуется доступ к сайту. Поделиться JSON можно любым обычным способом самостоятельно.

Форматы: внутренняя сцена версии 2; обёртки `ski-form-scene` и `ski-form-library` версии 1. Поддерживается импорт старого сырого JSON сцены версии 1. Входящие координаты, кватернионы, размеры, привязки, объём файла и распакованных ссылок ограничены и проверяются.

## Проверка

`node --import ./tests/register.mjs --test ./tests/studio.test.mjs`

12 тестов: длины костей и пределы IK, все позы при росте 100–210 см, сохранение мирового положения при привязке, подъём пятки, опора палки, разделение двух палок в одной руке, постоянные размеры инвентаря, миграция старых сцен, валидация некорректных данных, крайние значения полей, передача сцены по ссылке и атомарная проверка импорта набора.

В браузере проверены смена состава сцены и позы, редактирование корпуса и кисти, рост, создание/обновление/переименование пресета, импорт набора JSON, создание и открытие ссылки, экспорт библиотеки и PNG.

Горячие клавиши: G — двигать, R — вращать, F — вписать, Esc — снять выделение, Ctrl+A — все, Ctrl+Z — отменить, Ctrl+Shift+Z — повторить, Ctrl+S — скачать JSON.
