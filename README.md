# Ski Form

Браузерная студия композиций беговых лыж и палок. Приблизительная параметрическая геометрия по референсу Denton Aura, без текстур и надписей. Все размеры и формы являются художественным приближением.

Запуск: `node server.mjs`, затем http://127.0.0.1:4173. Статическая версия находится в `dist/`; зависимости Three.js 0.180.0 включены локально. Для модулей нужен HTTP сервер; открытие index.html через file:// не поддерживается. Шрифт Golos Text загружается из Google Fonts с системным запасным шрифтом.

Возможности: четыре независимых предмета, множественное выделение Shift+клик, перемещение и вращение гизмо и числовыми полями, мировые/локальные оси, привязка, шесть раскладок, пять ракурсов, перспектива/ортография, параметры геометрии, три матовых материала, студийный свет и тень, PNG 1024/2048/4096, четыре формата кадра, белый/серый/прозрачный фон, JSON импорт/экспорт, локальные композиции, автосохранение, история отмены.

Автосохранение и библиотека композиций используют localStorage текущего браузера. Данные не передаются на сервер. Для переноса используйте JSON файл. Изображения экспортируются без гизмо, выделения и сетки. При прозрачном фоне тень сохраняет полупрозрачность и отключается в настройках сцены.

Горячие клавиши: G — двигать, R — вращать, F — вписать, Esc — снять выделение, Ctrl+A — все, Ctrl+Z — отменить, Ctrl+Shift+Z — повторить, Ctrl+S — скачать JSON.

Зависимости: Three.js, лицензия MIT, `dist/vendor/LICENSE`.
