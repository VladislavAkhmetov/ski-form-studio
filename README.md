# Ski Form

Браузерная студия композиций беговых лыж и палок. Приблизительная параметрическая геометрия по референсу Denton Aura, без текстур и надписей. Все размеры и формы являются художественным приближением.

Запуск: `node server.mjs`, затем http://127.0.0.1:4173. Статическая версия находится в `dist/`; зависимости Three.js 0.180.0 включены локально. Для модулей нужен HTTP сервер; открытие index.html через file:// не поддерживается. Шрифт Golos Text загружается из Google Fonts с системным запасным шрифтом.

Возможности: четыре независимых предмета, множественное выделение Shift+клик, перемещение и вращение гизмо и числовыми полями, мировые/локальные оси, привязка, шесть раскладок, пять ракурсов, перспектива/ортография, параметры геометрии, три матовых материала, студийный свет и тень, PNG 1024/2048/4096, четыре формата кадра, белый/серый/прозрачный фон, JSON импорт/экспорт, локальные композиции, автосохранение, история отмены.

Крепления приближены к NNN Step по предоставленным референсам: фигурная носовая платформа, объёмный светлый рычаг с выемкой и ребристой вставкой, шесть углублений в направляющей платформе, поперечная ось и отдельная пятка с каналами и утопленным винтом. Рисунки и надписи не используются.

В «Предмет» → «Геометрия комплекта» доступны три варианта: NNN Step, условный прямоугольник и без креплений. Прямоугольник заменяет весь узел одним тёмным узким блоком длиной 34 см; его цвет остаётся тёмным при любом материале комплекта. Выбор применяется к обеим лыжам, сохраняется в композициях и JSON. Старые сцены без типа креплений сохраняют прежнее состояние: NNN Step либо без креплений.

Вкладка «Сцена» → «Тени» отключает все отбрасываемые тени, включая тени на предметах. Объёмное освещение материалов остаётся включённым. Настройка действует и в PNG.

«Земля» — конечная плоскость в XZ с заливкой, контуром и сеткой 20 см. По умолчанию выключена. Высота Y фиксирована; перемещение лыж не поднимает землю. Размеры и высота редактируются в сантиметрах, «Под комплект» устанавливает поверхность под нижней точкой видимых предметов. Переключатель «Земля в PNG» независимо управляет её включением в экспорт. Поле земли сохраняется вместе со сценой, старые JSON версии 1 открываются с землёй, выключенной по умолчанию.

Автосохранение и библиотека композиций используют localStorage текущего браузера. Данные не передаются на сервер. Для переноса используйте JSON файл. Изображения экспортируются без гизмо, выделения и сетки редактора. Схематическая сетка земли экспортируется только при включённых «Показывать землю», «Сетка на земле» и «Земля в PNG». При прозрачном фоне тень сохраняет полупрозрачность и отключается в настройках сцены.

Горячие клавиши: G — двигать, R — вращать, F — вписать, Esc — снять выделение, Ctrl+A — все, Ctrl+Z — отменить, Ctrl+Shift+Z — повторить, Ctrl+S — скачать JSON.

Зависимости: Three.js, лицензия MIT, `dist/vendor/LICENSE`.
